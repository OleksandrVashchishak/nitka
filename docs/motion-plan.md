# Анімації кабінету — план

Мета: дуже непомітні, легкі UX-анімації для переходів між сторінками, появи списків і елементів. Користувач їх майже не помічає, але без них інтерфейс здається смиканим. Анімації не мають відволікати увагу й гальмувати роботу.

Орієнтири: Linear, Vercel Dashboard, Stripe, Raycast. Систему (токени, криві) беремо з Material 3, патерни — з Ant Design, амплітуду зменшуємо.

## Принципи

1. Анімуються тільки `opacity` і `transform`. Ніяких `height`, `width`, `top`, `margin`.
2. Тривалості:
   - мікро (hover, чекбокс, перемикач): ~120 мс
   - поява елементів, дропдауни: ~160–180 мс
   - модалки, контент сторінки: ~200–240 мс
3. Крива ease-out: standard `cubic-bezier(0.2, 0, 0, 1)`, для появи emphasized decelerate `cubic-bezier(0.05, 0.7, 0.1, 1)`.
4. Маленькі зсуви: 4–8 px, scale 0.96–0.98.
5. Закриття швидше за відкриття (~120 мс) або взагалі без анімації.
6. Stagger у списках: 20–30 мс між елементами, анімуються тільки перші 6–8, решта з'являється разом з останнім.
7. Список анімується тільки при першій появі. На пошук і фільтри анімації немає.
8. `prefers-reduced-motion: reduce` вимикає все, крім fade.
9. Хедер, сайдбар і нижня навігація при переходах стоять на місці, анімується тільки контент.

### Звідки що беремо

| Що | Звідки |
|---|---|
| Токени тривалості й криві | Material 3 |
| Дропдауни, селекти, меню | Ant (scale від точки прив'язки) |
| Перехід сторінок і табів | Material fade through, тихіший |
| Кроки візардів | Material shared axis (зсув по X) |
| Тости | Ant |
| Модалки | fade + scale 0.98→1 |

### Не беремо

- Ripple з Material: андроїдний вигляд, не пасує до fata.studio.
- Модалку Ant, що виростає з точки кліку: надто помітна.
- Container transform з Material: складно і ризиковано зі SSR.
- Бібліотеки (framer-motion тощо): усе робиться на CSS.
