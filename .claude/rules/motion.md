# Motion (анімації кабінету)

Анімації мають бути майже непомітні: прибирають «смикання», але не відволікають і не гальмують.
Повний план і обґрунтування: `docs/motion-plan.md`. Токени й патерни: `apps/web/src/styles/ui/_motion.scss`.

## Завжди

- **Тільки токени.** Жодних `0.2s ease` чи власних cubic-bezier у новому коді:
  - тривалість: `--motion-duration-fast` (120 мс, hover/мікро), `-base` (180 мс, дропдауни), `-slow` (240 мс, модалки/контент), `-exit` (140 мс, закриття)
  - криві: `--motion-ease-standard`, `--motion-ease-enter` (поява), `--motion-ease-exit` (зникнення)
  - амплітуда: `--motion-shift` (6px), `--motion-shift-sm` (4px), `--motion-scale` (0.97)
- **Анімуємо лише `opacity` і `translate` / `scale`** (окремі властивості). Не `height`/`width`/`top`/`margin`. Не `transform` у keyframes, якщо елемент позиціонується інлайн-`transform` (меню).
- **Закриття швидше за відкриття** або без анімації.
- **Reduced motion** обробляється глобально: токени зсуву/масштабу стають 0/1, лишається fade. Окремі `@media (prefers-reduced-motion)` не потрібні, якщо використовуєш токени.

## Готові патерни

| Що | Як |
|---|---|
| Модалка / дровер | `CabinetOverlay` — уже анімований, нічого не додавати |
| Дропдаун / поповер, що монтується умовно | додати клас у список у `_motion.scss` (`motion-drop-in`) або клас `.motion-drop` |
| Список, що з'являється | `const staggerRef = useStaggerOnce();` → `<ul ref={staggerRef}>` (тільки перша поява, пошук/фільтри не анімуються) |
| Блок, що з'являється | `.motion-rise` / `.motion-fade` / `.motion-pop` |
| Кроки візарда | умовний рендер кроку + `motion-step-in` |
| Перехід сторінки | нічого: `.cabinet-main > *` робить fade сам |

## Не можна

- `transform`/`translate` на контейнері, всередині якого є `position: fixed` (мобільні панелі, оверлеї) — fixed «відклеюється». Для таких — лише `opacity`.
- Анімація на кожен символ пошуку чи зміну фільтра.
- Stagger довший за 8 елементів, нескінченні декоративні анімації в кабінеті, ripple.
- Бібліотеки анімацій (framer-motion тощо) — усе на CSS.
- Публічний сайт `/w/[slug]` і лендінг живуть за своїми правилами, ці токени там не обов'язкові.
